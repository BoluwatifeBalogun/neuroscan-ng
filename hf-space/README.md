# NeuroScan NG Classifier

Gradio front-end for the VGG19 Alzheimer's MRI classifier (case study: Nigeria).
Runs in labelled demo mode until `alzheimer_vgg19.keras` and `labels.json`
(produced by the project's Colab training notebook) are uploaded next to `app.py`.
