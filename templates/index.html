Why early detection needs help in Nigeria

Specialist radiologists are scarce and unevenly distributed, so subtle Alzheimer's-related changes on MRI are easy to miss until cognitive decline is already advanced. NeuroScan NG gives every facility with a browser a consistent preliminary read.

Subtle patterns, surfaced

The network learns structural patterns of atrophy from thousands of labelled scans, including differences between healthy ageing and very mild impairment that are hard to describe by eye.

Consistent everywhere

The same trained model reads a scan the same way in Maiduguri, Lagos or Enugu. No dependence on which specialist happens to be on duty.

Seconds, not sessions

Upload, preprocess, classify: a preliminary result with a confidence score in under two seconds, so triage and referral decisions are not waiting on a reading queue.

From upload to preliminary result

A fixed, auditable pipeline, the same one described in the study methodology.

  1. 1

    Upload

    An authorised clinician uploads a brain MRI image. The file is validated for type, size and integrity before anything else happens.

  2. 2

    Preprocess

    The image is converted to RGB, resized to 224×224 and normalised, exactly matching how training images were prepared.

  3. 3

    Classify

    A fine-tuned VGG19 network assigns the scan to one of four classes: Non-Demented, Very Mild, Mild or Moderate Demented.

  4. 4

    Review

    The clinician sees the predicted class, its confidence score and the full probability breakdown, then applies clinical judgement. Every result is stored for follow-up.

Measured, not assumed

The model is evaluated the way the literature demands: a held-out test set the network has never seen, with accuracy, precision, recall, sensitivity, specificity, F1-score and a full confusion matrix published on the performance page.
