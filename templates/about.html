About the study

Design and Implementation of a Web-Based Intelligent System for Early Detection of Alzheimer's Disease from MRI Images using Convolutional Neural Networks. Case study: Federal Republic of Nigeria.

The problem

Alzheimer's disease is the leading cause of dementia, responsible for an estimated 60 to 70 percent of cases worldwide. It is usually identified only after noticeable decline in memory and reasoning, because the structural brain changes that precede symptoms are subtle and require specialist interpretation of MRI images. In Nigeria, where experienced neuroradiologists are concentrated in a handful of tertiary centres, most facilities have no consistent way to read these early patterns.

The approach

NeuroScan NG applies transfer learning with the VGG19 convolutional neural network. The ImageNet-pretrained convolutional base extracts visual features, and a new classification head is trained on a labelled dataset of about 6,400 brain MRI images across four classes: Non-Demented, Very Mild Demented, Mild Demented and Moderate Demented. Images are validated, resized to 224×224 pixels and normalised before both training and inference, with the dataset split into training, validation and held-out test sets to prevent data leakage.

Evaluation

Following the concerns raised in the reviewed literature about inflated and irreproducible results, the model is evaluated on a test set it never saw during training, using accuracy, precision, recall, sensitivity, specificity, F1-score and a confusion matrix. All figures are published on the model performance page.

What the system is, and is not

NeuroScan NG is a decision-support system. Its output is a preliminary classification with a confidence score, intended to assist qualified professionals in assessment and referral. An MRI image alone does not confirm Alzheimer's disease, and no prediction from this system replaces clinical history, cognitive testing, neurological examination or professional judgement.

Technology

The web application is built with Flask and SQLite, and the model is trained and served with TensorFlow and Keras. The system records each authorised user's analyses so that results can be revisited and compared over time.
